# Rivalry Royale

Rivalry Royale is a Roblox script designed to enhance the gameplay experience by managing characters, players, game states, and leaderboards. It provides a comprehensive set of tools for developers to create competitive and engaging Roblox experiences. The script includes modules for character management, player handling, game state control, leaderboard updates, and user interface management.

## Install

1. Download the Rivalry Royale script files from the GitHub repository.
2. Place `CharacterManager.server.lua` in the ServerScriptService.
3. Place `GameManager.server.lua` in the ServerScriptService.
4. Place `LeaderboardManager.server.lua` in the ServerScriptService.
5. Place `PlayerManager.server.lua` in the ServerScriptService.
6. Place `UIManager.client.lua` in the StarterPlayerScripts.

## Use

1. **Character Management**: The `CharacterManager.server.lua` script handles character-specific logic and events. It sets the walk speed and jump power for each character when they are added to the game.
2. **Player Management**: The `PlayerManager.server.lua` script manages player-specific logic and events. It prints messages when players join or leave the game.
3. **Game State Control**: The `GameManager.server.lua` script controls the main game logic and state management. It includes functions to start and end the game.
4. **Leaderboard Updates**: The `LeaderboardManager.server.lua` script handles leaderboard updates and displays. It prints messages when updating the leaderboard for a player.
5. **User Interface Management**: The `UIManager.client.lua` script manages the user interface for players. It displays notifications using the StarterGui service.
